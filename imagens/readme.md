# 🧩 Projeto Serenamente - Apoio à Saúde Mental

O **Serenamente** é um projeto focado em acolhimento e informação para pessoas que convivem com ansiedade e transtornos de humor.

## 📺 Demonstração do Sistema (Pitch)
Como este projeto utiliza PHP e MySQL via XAMPP, preparei um vídeo demonstrativo mostrando o funcionamento do CRUD (Cadastro, Consulta, Edição e Exclusão):

👉 [**Assistir demonstração no Google Drive**](https://drive.google.com/file/d/1xPhxLKGVp_9YAwAiTU2HNmIn53JQLW30/view?usp=sharing)

## 🛠️ Tecnologias
- **Frontend:** HTML5, CSS3 (Flexbox/Responsivo), JavaScript (jQuery/AJAX).
- **Backend:** PHP (API REST).
- **Banco de Dados:** MySQL.

## 🚀 Como testar localmente
1. Clone o repositório.
2. Certifique-se de ter o XAMPP instalado.
3. Importe o banco de dados e aponte a API no arquivo `serenamente.js`.
